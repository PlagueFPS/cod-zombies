## This Jazz is Classified
This side quest has players interact with five terminals in the **War Room: Lower Level**, each of which will emit a morse code number (1-5).
You must interact with each terminal in order of 1-5, to activate the music easter egg song "This Jazz is Classified" by [Jack Wall](https://www.jackwall.net/).
