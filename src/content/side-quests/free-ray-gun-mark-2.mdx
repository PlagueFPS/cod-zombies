## Free Ray Gun Mark II
> This needs to be done on **Round 14** or later to receive the **Ray Gun MK II** as the reward scales with round.

Open up all areas of the map by breaking down the wooden walls with **Ol' Tessie**, then complete one loop around the map using jump pads, meaning you must have taken every
jump pad at least once to complete a loop around the map. Afterwards, progress four rounds until you see a flashing light in the **Janus Towers Plaza** area on the side of the tower.

<RichImage image="/content/ashes-of-the-damned/aotd-free-ray-gun-mark-2-flashing-light.webp" caption="Flashing light in Janus Towers Plaza" />

This light will be flashing a code indicating the order in which you need to take the jump pads around the map. The first number flashes will always be **7** or **3**, both of which
correspond to an **Ashwood** jump pad. Use the list below to know the order of the jump pads you need to take with your code:

- 1 - Janus Towers Plaza Jump Pad
- 2 - Vandorn Farm Jump Pad
- 3 - Ashwood Jump Pad going towards **Exit 115** or **Zarya Cosmodrome**
- 4 - Blackwater Lake Jump Pad
- 5 - Exit 115 Jump Pad
- 6 - Zarya Cosmodrome Jump Pad
- 7 - Ashwood Jump Pad going towards **Blackwater Lake** or **Vandorn Farm**

> The flashing light in spawn will repeat its code infinitely, with a white flash indicating the end of the code before it begins again. Make sure you have the right code before starting,
the first jump pad will always be one of the **Ashwood** jump pads, which means you need to use **Ol' Tessie** to drive to **Ashwood** or run there, as you cannot use jump pads during this.

If done correctly, a purple tear in the **Dark Aether** will appear in the air, in one of the jump pad paths. Once you find it, take the jump pad that has that path so that you land within the tear,
teleporting you to **Ashwood**, where you will receive a bunch of loot, including the free **Ray Gun MK II** wonder weapon.

<RichImage image="/content/ashes-of-the-damned/aotd-free-ray-gun-mark-2-purple-tear.webp" caption="Purple Tear in the Dark Aether" />
<RichImage image="/content/ashes-of-the-damned/aotd-free-ray-gun-mark-2.webp" caption="Free Ray Gun MK II" />

> If you take the jump pads in the wrong order, you'll need to wait one round before getting a new code. If you do not find the purple tear before it disappears, you will need to wait another four rounds before starting the quest over again.
