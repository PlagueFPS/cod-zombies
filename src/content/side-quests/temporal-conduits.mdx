## Temporal Conduits
During a **Special Round** one character in the game will get a specific **Temporal Conduit** to spawn in one of the four **Shadowsmith** temples. Interact with one of these
conduits will teleport you into a memory where you'll learn more about the story and upon coming out, you'll receive great rewards like **Mystery Perks**, **Aether Tools**,
**Aetherium Crystals**, and potentially more.

<RichImage image="/content/rex-infernus/rex-infernus-temporal-conduit.webp" caption="Temporal Conduit" />

> It seems only one **Temporal Conduit** will spawn during these rounds, and only that character can see it.
